<sub>**How these numbers are counted.** Stars / forks / repos cover my own non-fork repositories. Visitors and views come from GitHub's official traffic API, sampled daily by [devcheck's metrics workflow](https://github.com/iihao/devcheck/tree/main/metrics) — GitHub only keeps 14 days, so these are *cumulative recorded* values: a visitor who returns on another day is counted again, so the real unique-visitor count is lower. No third-party hit counter, no self-refresh inflation. Badges refresh with the daily cron (a few minutes of CDN cache on top).</sub>
